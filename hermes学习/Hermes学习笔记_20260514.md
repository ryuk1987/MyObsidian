# Hermes 学习笔记

## SOUL.md 与 Personalities 冲突问题

> 来源：2026-05-14 与 Captain Hermes 的对话

---

### Q: SOUL.md 和 config.yaml 中的 personalities 属性内容不会冲突吗？

不会冲突，是**分层叠加**的关系。SOUL.md 是底层，personalities 是在它上面叠的一层。

---

### Q: 编写 SOUL.md 时是不是要注意不要跟 personalities 重复？

是的，尽量不要重复。personalities 是追加到 SOUL.md 后面的，LLM 在处理冲突时会更多地遵循后面的内容（context 末尾偏置）。如果两边写了相同的身份声明，personalities 会覆盖 SOUL.md 的内容。

**建议**：
- **SOUL.md**：写通用身份、价值观、行为原则（始终加载）
- **Personalities**：只写附加的风格/语气指令，不要重复 SOUL.md 的核心身份描述

---

### Q: 这是 Hermes 的处理结果还是大模型的处理结果？

是 **LLM 自己决定的**，不是 Hermes 强制覆盖的。

Hermes 只是简单拼接：
```python
# run_agent.py line 10899-10900
effective_system = (_cached_system_prompt + "\n\n" + self.ephemeral_system_prompt).strip()
```

没有任何"覆盖"、"优先级"的逻辑——LLM 自己决定冲突时谁优先。
