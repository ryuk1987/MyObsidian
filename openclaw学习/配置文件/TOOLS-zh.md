# TOOLS.md - 本地笔记

Skill 定义工具_如何_工作。这个文件放的是_你_的 specifics — 只有你独有的东西。

## 这里放什么

比如：

- 摄像头名称和位置
- SSH 主机和别名
- 偏好的 TTS 声音
- 音箱/房间名称
- 设备昵称
- 任何环境特定的东西

## 示例

```markdown
### 摄像头

- living-room → 主区域，180° 广角
- front-door → 入口，移动触发

### SSH

- home-server → 192.168.1.100, user: admin

### TTS

- 偏好的声音："Nova"（温暖，略英式）
- 默认音箱：Kitchen HomePod
```

## 为什么分开？

Skill 是共享的。你的设置是你的。这样分离意味着更新 skill 不会丢失你的笔记，分享 skill 不会泄露你的基础设施。

---

加上任何能帮你工作的东西。这是你的 cheat sheet。
